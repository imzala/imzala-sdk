# Değişiklik günlüğü

Bu paket [Semantic Versioning](https://semver.org/lang/tr/) izler.

## 1.0.0

İlk kararlı sürüm; semver sözü bu sürümle başlar.

### Değişti

- Sürüm uyumu notu: bu sürüm API v1 `1.8.14` ile birlikte kullanılır (README'deki "Sürüm uyumu" tablosu). İmza oturumu sunucuda `@imzala/node` veya diğer sunucu SDK'larıyla üretilir; tarayıcıya yalnız kısa ömürlü, tek kullanımlık token iner.
- Paketin API yüzeyi (iframe ve `postMessage` olayları) **değişmedi**; 0.x'ten yükseltme kod değişikliği gerektirmez.
